# Guidance

## Purpose

Owns the reader’s choice of learning path after reading and reflection. Coordinates transition into Understanding or Saar.

## Owned concepts

- GuidanceSession
- GuidancePathSelection
- Supported paths (Understand, Connect, Traditional Commentary, Ask Saar)

## Expected dependencies

- Scripture
- Reflection
- Understanding
- Saar (path handoff only)
- Identity
- Platform
- Shared

Guidance does not generate AI responses.

## Current status

Module marker only. No product features implemented yet.
