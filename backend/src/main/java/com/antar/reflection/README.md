# Reflection

## Purpose

Owns reader-authored writing: quick reflections and deep journal entries tied to a verse.

## Owned concepts

- ReflectionEntry
- ReflectionType (QUICK, DEEP)
- ReflectionStatus
- ReflectionRevision
- Reflection content and timestamps

## Expected dependencies

- Scripture (verse reference via published interfaces)
- Identity (reader ownership)
- Platform
- Shared

Reflection content must never be modified or analyzed silently by AI.

## Current status

Module marker only. No product features implemented yet.
