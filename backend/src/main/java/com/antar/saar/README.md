# Saar

## Purpose

Owns conversational AI companionship: conversations, retrieval, grounding, citations, and safety controls.

## Owned concepts

- Conversation
- Message
- Citation
- Retrieval and generation workflow
- Grounding and safety status

## Expected dependencies

- Scripture (via published query interfaces)
- Understanding (approved curated sources)
- Reflection (only with explicit authorization)
- Identity
- Platform (provider clients, observability)
- Shared

Saar must not access other modules’ infrastructure packages directly.

## Current status

Module marker only. No product features implemented yet.
