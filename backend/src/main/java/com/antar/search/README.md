# Search

## Purpose

Owns content discovery across approved searchable domains. Search does not own the content it returns.

## Owned concepts

- Canonical-reference parsing
- Keyword and full-text search
- Semantic search where appropriate
- Search projections and result ranking coordination

## Expected dependencies

- Scripture
- Understanding
- Platform
- Shared

Private reflections must never be exposed through public Search APIs.

## Current status

Module marker only. No product features implemented yet.
