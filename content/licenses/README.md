# `content/licenses/`

License catalog for content sources.

## Rules

- Record the license **as displayed** at acquisition time.
- Store full license text when redistribution requires it.
- `APPROVED_FOR_IMPORT` requires a catalog entry and clearance consistent with Antar policy.
- Displayed public-domain / CC0 labels do **not** by themselves authorize canonical import when edition numbering mismatches Antar.

## Files

| File | Role |
|------|------|
| `catalog.json` | Machine-readable license catalog |
| `cc0-1.0.txt` | CC0 1.0 Public Domain Dedication (reference note) |
| `cc-by-sa-4.0.txt` | CC BY-SA 4.0 reference note (Wikisource contributor layer) |
