# NAVIGATION COMPONENTS

Navigation components help readers understand where they are, where they can go, and how to continue without unnecessary decision-making.

This family currently includes:

- `TOP_NAVIGATION.md`
- `CONTINUE_READING.md`

Navigation components should:

- preserve context,
- follow familiar platform behavior,
- remain visually secondary to content,
- minimize competing actions,
- and avoid owning routing or business logic.

Primary destinations, entry points, and reader journeys are defined by Experience specifications and Interaction Blueprints.
