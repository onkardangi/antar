# SCRIPTURE COMPONENTS

Scripture components present the Bhagavad Gita and its supporting reading content with clarity, consistency, and respect.

Planned components include:

- Verse Reference
- Verse Block
- Transliteration Block
- Translation Block
- Saar

Scripture components should:

- keep the teaching visually primary,
- separate scripture from interpretation,
- support multilingual reading,
- remain accessible at all supported text sizes,
- and avoid unrelated actions or decorative interface.

The Verse experience determines the reading sequence.

These components define only reusable content presentation and behavior.
