# LIBRARY COMPONENTS

Library components help readers discover and navigate the structure of the Bhagavad Gita without turning discovery into an endless content feed.

Planned components include:

- Chapter Item
- Verse List
- Search Field
- Search Result

Library components should:

- preserve canonical chapter order,
- support intentional discovery,
- provide enough context without replacing reading,
- and avoid popularity rankings, trending content, or algorithmic pressure.

Chapter remains an experience.

There should not be a generic `Chapter` component.

The Chapter experience may compose Navigation, Library, and Scripture components.
