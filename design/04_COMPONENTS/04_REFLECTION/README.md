# REFLECTION COMPONENTS

Reflection components help readers turn reading into personal meaning without pressure or judgment.

Planned components include:

- Reflection Invitation
- Journal Editor
- Save Status
- Reflection Preview

Reflection components should:

- make reflection optional,
- protect reader privacy,
- preserve the reader’s own voice,
- avoid evaluation or performance metrics,
- and remain connected to the teaching that inspired the reflection.

AI may support reflection but must never write on behalf of the reader.
