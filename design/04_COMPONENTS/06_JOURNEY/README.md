# JOURNEY COMPONENTS

Journey components help readers revisit meaningful teachings, reflections, and Saar without turning personal growth into measurement.

Planned components include:

- Journey Memory
- Reflection Preview
- Saar Collection
- Journey Timeline Entry

Journey components should:

- prioritize meaningful memories over activity history,
- keep memories anchored to scripture,
- avoid scores, streaks, achievements, and psychological labels,
- preserve reader ownership of interpretation,
- and encourage movement back toward reading and reflection.
