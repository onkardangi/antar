# Antar Design Principles

Status: Canonical

Purpose:

This document defines the timeless principles that guide every product, design, and engineering decision within Antar.

These principles exist independently of individual screens or implementation details.

Every new feature should strengthen these principles rather than compete with them.

---

# 1. Scripture Before Interface

The Bhagavad Gita is always the primary content.

The interface exists only to support engagement with scripture.

Technology should disappear whenever possible.

Questions to ask:

- Does this help the reader engage with scripture?
- Or is it competing for attention?

---

# 2. Reading Before Reflection

Readers should first experience the verse.

Reflection begins only after the verse has been read.

The application should never interrupt scripture with writing prompts, AI explanations, or secondary actions.

Reading always comes first.

---

# 3. Reflection Before Guidance

Readers should be encouraged to form their own understanding before receiving external interpretation.

Guidance, Saar, and AI assistance are always optional and always secondary.

Antar supports contemplation rather than replacing it.

---

# 4. One Responsibility Per Screen

Every screen exists to answer one primary question.

Home

"What should I do next?"

Chapter

"Where do I want to read?"

Verse

"What is this verse saying?"

Reflection

"What stands out to me?"

Journey

"What have I discovered?"

No screen should duplicate another screen's responsibility.

---

# 5. One Primary Action

Every screen should make one action feel obvious.

Competing primary actions create cognitive friction.

If multiple actions appear equally important, the design should be reconsidered.

---

# 6. Calm Over Engagement

Antar is not designed to maximize time spent.

It is designed to maximize meaningful engagement.

Avoid mechanics that encourage compulsive interaction.

Examples:

- streaks
- badges
- achievements
- XP
- endless feeds
- engagement loops

Success is measured by meaningful reading rather than frequent interaction.

---

# 7. Typography Carries Hierarchy

Visual hierarchy should primarily emerge through:

- typography
- spacing
- rhythm
- composition

Avoid relying on decorative styling to communicate importance.

Whitespace is a design tool rather than empty space.

---

# 8. Minimal Interface

Every visible element should have a clear purpose.

If an element does not help the reader:

- orient,
- read,
- reflect,
- remember,

it should be questioned.

Interface should never become decoration.

---

# 9. Progressive Depth

Readers should never feel overwhelmed.

Experiences should unfold naturally.

Example:

Read

↓

Capture a Thought

↓

Reflect More

↓

Guidance

↓

Saar

Each step introduces slightly more depth without forcing it.

---

# 10. AI Is a Companion

AI exists to deepen understanding.

It never replaces reading.

It never becomes the primary experience.

AI should feel like a thoughtful companion rather than a search engine or chatbot.

---

# 11. Personal Before Analytical

Antar values personal growth over measurable progress.

Journey emphasizes remembrance rather than metrics.

Reflection emphasizes sincerity rather than productivity.

Readers should feel understood rather than evaluated.

---

# 12. Consistency Builds Trust

Every experience should feel like part of the same journey.

Home

↓

Chapter

↓

Verse

↓

Reflection

↓

Journey

should feel like one continuous conversation.

Consistency in spacing, typography, interaction, and tone builds familiarity and trust.

---

# 13. Simplicity Requires Discipline

New features must justify their existence.

Before introducing a feature, ask:

Does this simplify the reader's experience?

Or does it merely increase functionality?

Functionality without clarity should be rejected.

---

# 14. Technology Supports Contemplation

Technology should quietly support the reader.

It should not become the focus.

The best interaction is often the one the reader barely notices.

---

# Emotional Journey

Every core experience supports the following progression.

Invite

↓

Orient

↓

Read

↓

Reflect

↓

Remember

Future experiences should strengthen this emotional journey rather than interrupt it.

---

# Decision Framework

When evaluating a new feature, ask:

1. Does it strengthen scripture?
2. Does it reduce cognitive load?
3. Does it preserve calmness?
4. Does it support contemplation?
5. Does it respect the current screen's responsibility?
6. Does it introduce another competing primary action?
7. Would removing it make the experience better?

If multiple answers raise concern, the feature should be reconsidered.

---

# Guiding Thought

Antar is not designed to help people consume more content.

It is designed to help people encounter timeless wisdom with greater attention, reflection, and presence.

Every design decision should reinforce that purpose.
