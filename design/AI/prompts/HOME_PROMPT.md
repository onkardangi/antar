# Screen

Home

Version: 1.0

Purpose:

Help the reader immediately understand the next meaningful action in their journey through the Bhagavad Gita.

The Home screen is intentionally minimal.

It should never feel like a dashboard.

It should never feel like a content feed.

It should quietly invite the reader into scripture.

---

# Primary User Question

When I open Antar...

"What should I do next?"

Everything on this screen should answer that question.

---

# Primary Goal

Guide the reader toward today's scripture.

Today's Invitation should always be the visual focal point.

---

# Information Hierarchy

The screen should follow this hierarchy exactly.

1. Top Navigation

2. Today's Invitation

3. Browse Bhagavad Gita

No additional primary sections should be introduced.

Top Navigation

Today's Invitation (Composition)

Browse Chapters Entry

# Today's Invitation

Today's Invitation is the primary focus of the Home screen.

It is a contextual composition that presents one already-selected next step. Depending on reader context, it may show:

• a new-reader starting point,

• continuation from reading progress,

• an unfinished reflection to resume,

• or an approved curated teaching.

It should be composed of:

• Destination context

• A compact preview appropriate to the selected destination

• Continue Reading

It may optionally include:

• One sentence explaining the selected step.

Show only one state at a time.

It must never become a recommendation card.

It must always lead toward scripture or scripture-rooted reflection.

---

# Browse Bhagavad Gita

This is a simple navigation entry.

It is not a chapter browser.

It should not display multiple chapters.

It simply provides a way into the Library experience.

Examples:

Browse Bhagavad Gita →

Browse Chapters →

Explore the Gita →

Only one compact entry should appear.
