# VERSE_PROMPT.md

Before generating this screen, read **FIGMA_CONTEXT.md** completely.

This document defines the philosophy, architecture, and constraints of Antar.

Do not generate this screen without following those rules.

---

# Screen

Verse

Version: 1.0

Purpose:

The Verse experience is the heart of Antar.

Every other experience exists to guide the reader here.

This screen should help the reader experience scripture without unnecessary interface.

The interface should quietly disappear behind the teaching.

---

# Primary User Question

"What is this teaching inviting me to understand?"

---

# Primary Goal

Create an environment that encourages slow, intentional reading.

The scripture should always be the visual focal point.

---

# Approved Components

Top Navigation

Scripture Stack (Composition)

Reflection Stack (Composition)

Continue Reading

Only use documented ADL components.

Do not invent additional sections.

---

# Information Hierarchy

The screen should follow this order exactly.

1. Top Navigation

2. Scripture Stack

3. Reflection Stack

4. Continue Reading

No additional primary sections.

---

# Scripture Stack

Scripture Stack is composed of:

• Verse Reference

• Verse Block

• Transliteration Block

• Translation Block

The scripture should occupy the greatest visual emphasis.

Maintain generous spacing between each section.

Readers should never feel rushed.

---

# Reflection Stack

Reflection Stack is composed of:

• Reflection Invitation

• Journal Editor

• Save Status

• Saar

Reflection should always follow scripture.

Readers should encounter the teaching before they encounter themselves.

---

# Continue Reading

Continue Reading appears after Reflection.

It quietly encourages readers to continue the journey.

It should never compete with scripture.

---

# Layout Principles

Design for:

• calm

• breathing room

• focus

• rhythm

• readability

Avoid visual density.

Avoid excessive scrolling caused by decorative elements.

Whitespace is intentional.

---

# Visual Hierarchy

The visual order should be:

Scripture

↓

Reflection

↓

Continue Reading

The interface itself should have the least visual weight.

---

# Reading Experience

The Verse screen should feel closer to reading a beautiful book than using a productivity application.

Avoid dashboard thinking.

Avoid card-heavy layouts.

Avoid interruptions.

---

# Interaction Rules

Readers should naturally progress through:

Read

↓

Reflect

↓

Continue

The interface should support this flow without forcing it.

---

# Forbidden Features

Do not generate:

• AI chat windows

• floating action buttons

• reaction buttons

• likes

• comments

• streaks

• achievements

• XP

• progress rings

• share prompts

• social widgets

• promotional cards

• advertisements

• multiple CTAs

The Verse screen is a reading experience.

---

# Wireframe Rules

Generate only a grayscale wireframe.

Use rectangles and placeholder text.

Do not apply branding.

Do not use gradients.

Do not use shadows.

Do not invent iconography.

Focus only on layout and hierarchy.

---

# Success Criteria

The screen succeeds if readers instinctively understand:

1. Read the teaching.

2. Reflect on it.

3. Continue the journey.

The interface should disappear behind the scripture.
