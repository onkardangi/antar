# ADR-001 — Home Has One Primary Action

## Status

Accepted

## Context

The Home screen originally contained multiple competing destinations:
- Continue Journey
- Today's Reflection
- Yesterday's Reflection
- Browse

This created competing visual hierarchy and decision fatigue.

## Decision

Home presents one primary action only.

That action is Today's Invitation.

Today's Invitation presents a single already-selected next meaningful step.

Examples:

- Begin Journey
- Continue Reading
- Resume Reflection
- Curated Teaching

Selection happens elsewhere in the product.

Home only presents the invitation.

## Consequences

- One obvious next action.
- Less cognitive load.
- Calm first impression.
- Home becomes an invitation rather than a dashboard.
