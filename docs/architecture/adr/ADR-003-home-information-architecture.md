# ADR-003 — Home Is an Invitation, Not a Dashboard

## Status

Accepted

## Context

Many modern applications overload Home with metrics, recommendations, feeds, and shortcuts.

Antar intentionally rejects this pattern.

## Decision

Home contains only:

Top Navigation

↓

Today's Invitation

↓

Browse Bhagavad Gita

Nothing else.

## Consequences

- Reduces decision fatigue.
- Encourages reading immediately.
- Creates a calm entry into the experience.
