# ADR-009 — Respect the Silence

## Status

Accepted

## Context

Modern software encourages constant interaction.

Contemplative reading often benefits from pauses rather than immediate answers.

## Decision

Saar should not answer every question immediately.

Sometimes it should:

- invite further reflection
- encourage returning to the verse
- acknowledge uncertainty
- allow space for contemplation

Silence is a feature rather than missing functionality.

## Consequences

- Encourages thoughtful reading.
- Prevents over-dependence on AI.
- Supports the contemplative nature of Antar.
